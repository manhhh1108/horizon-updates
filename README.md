# horizon-updates

Chỉ chứa `selectors.yaml` cho Horizon X Media Tool.

Khi ChatGPT hoặc Grok đổi giao diện, cập nhật file này và push. Phần mềm trên
máy khách bấm **Kiểm tra cập nhật** là tải về ngay — không phải build lại,
không phải gửi file.

Repo này **công khai** vì phần mềm cần tải file qua https mà không có đăng nhập.
Trong file chỉ có selector CSS và biểu thức nhận dạng — không có mã nguồn,
không có khoá, không có dữ liệu khách.
